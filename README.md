第一階段：獲取老師的範本 (10 分鐘)
進入老師專案：點擊老師提供的 GitHub 網址：https://github.com/PeterShiaush/Hello-Streamlit。
開啟 Colab：在檔案清單中，點選副檔名為 .ipynb 的筆記本檔案，接著點擊上方的 「Open in Colab」 按鈕。
儲存副本 (最關鍵步驟)：進入 Colab 後，請點選左上角「檔案」 > 「在雲端硬碟儲存副本」。
